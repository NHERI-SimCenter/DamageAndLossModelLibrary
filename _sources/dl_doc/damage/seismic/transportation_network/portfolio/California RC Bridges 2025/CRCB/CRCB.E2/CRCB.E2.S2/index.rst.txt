   <p class="dl_comp_name"><b>CRCB.E2.S2.C1.D.System.BoxGirder.Circ.M17</b> | Bridge system fragility for an Era 2 (1971–1990) bridge with two spans, single-column bents, and diaphragm abutments. Model attributes: box-girder deck, circular columns.</p>
   <div>

| DesignSafe PRJ-5910 v1, Sa_1_Fragility Database.csv, data row 132 (spreadsheet row 134), group E2-S2-C1-D, System; source note "Box-girder, circular column". The curve is a series-system fragility that the source study derived from correlated component demands. This curve and the component curves of the same group (seismic/transportation_network/component/California RC Bridges 2025) are two representations of the same bridge. Apply one or the other to a given bridge, because applying both to the same bridge double-counts its damage; different bridges in one regional assessment may use different representations.
| Source study: Mangalathu (2017), a doctoral thesis that groups California box-girder bridges into classes by design era, span count, bent type, abutment type, and column shape, and derives component and system fragilities for each class from nonlinear time-history analyses. The fragility analyses use 320 scaled motions from 228 records of a Caltrans NGA-West2 suite listed in thesis Appendix A. Sa(1.0 s) is the RotD50 spectral acceleration at 5% damping: for 317 of the 320 motions, the Appendix A value equals the NGA-West2 RotD50 value times the tabulated scale factor.
