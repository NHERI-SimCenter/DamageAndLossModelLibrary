.. _changes_v3_2:

=============================
Version 3.2 (October 2, 2026)
=============================

This release adds three datasets of seismic fragility models for California reinforced concrete bridges from the Chen et al. (2025) database: bridge system models, bridge component models, and EDP-based bridge component models. Twelve new demand types support the models conditioned on the response of a bridge component. The Hazus water network pipeline models gain metadata, the Hazus datasets are retitled by methodology and version, and the DLML Explorer gains Asset type and Source filters on the Browse and Search page.

Added
-----

- **California RC bridge fragilities (Chen et al. 2025):** two datasets from the Sa(1.0 s)-based fragility database of Chen et al. (2025, Earthquake Spectra 41(4)), published on DesignSafe as PRJ-5910. ``seismic/transportation_network/portfolio/California RC Bridges 2025`` holds 116 bridge system models and ``seismic/transportation_network/component/California RC Bridges 2025`` holds 801 bridge component models, covering 26 bridge groups by design era, span count, bent type, and abutment type. Each model's metadata cites its source study and records every correction made to the published values or labels.
- **Bridge component demand types:** twelve new ``EDP_TYPES`` entries for fragility models conditioned on the response of a bridge component: Peak Column Curvature Ductility (``CCD``), Peak Column Drift Ratio (``CDR``), Peak Joint Opening (``JOP``), Peak Abutment Active Displacement (``ABA``), Peak Abutment Passive Displacement (``ABP``), Peak Abutment Transverse Displacement (``ABT``), Peak Bearing Deformation (``BRD``), Peak Deck Displacement (``DEC``), Peak Foundation Translation (``FNT``), Peak Foundation Rotation (``FNR``), Peak Shear Key Deformation (``KEY``), and Permanent Approach Settlement (``PAS``).
- **California RC bridge EDP-based fragilities (Chen et al. 2025):** ``seismic/transportation_network/component/California RC Bridges 2025 EDP`` holds 25 bridge component models from the EDP capacity table of the Chen et al. (2025) database. Each model is conditioned on the response of the component (peak values; the permanent settlement for approaches) instead of Sa(1.0 s): column curvature ductility or drift ratio; joint opening; abutment, deck, or foundation displacement; bearing or shear key deformation; foundation rotation; or approach settlement. Each model's metadata names the source of its capacities and records every change made to the published values.
- **Hazus water pipeline metadata:** ``seismic/water_network/portfolio/Hazus v6.1`` gains ``fragility.json``, so its four pipeline models (brittle and ductile pipes under ground shaking and ground failure) carry descriptions, limit states, and a reference, and appear in the Explorer and the documentation.

Changed
-------

- **Dataset titles and descriptions:** the Hazus datasets are titled by methodology and version (``Hazus Earthquake Methodology v5.1``, ``Hazus Earthquake Methodology v6.1``, ``Hazus Hurricane Methodology v5.1``), with the asset type dropped from the title and "HAZUS" written as "Hazus"; the story-level building dataset is ``Hazus Earthquake Methodology v5.1, story-level prototype``, with a description of how it was derived; the v6.1 description names version 6.1 and the two added design levels; the original hurricane description names version 5.1 instead of 4.2; the California RC bridge datasets are titled ``California RC Bridges 2025 (Chen et al.): Systems``, ``California RC Bridges 2025 (Chen et al.): Components``, and ``California RC Bridges 2025 (Chen et al.): Components, EDP-based``, and their descriptions are organized in paragraphs.
- **DLML Explorer:** on the Browse and Search page, the Dataset selector is renamed Collection (Fragility, Consequence, All), and an Asset type filter joins the Hazard and Source filters, each list narrowed by the selections before it; choosing a Source opens that source without expanding its models; the tree groups sources under asset-type headings where a hazard section holds more than one asset type; the Component group filter and the source badges are gone.
- **Explorer dependencies:** the ``explorer`` extra requires Streamlit 1.58 or later on Python 3.10 and later.

Removed
-------

- The root ``model_files.txt`` manifest, which described the pre-v3.0 top-level data layout and no longer matched the packaged data.

Fixed
-----

- **Documentation:** dataset descriptions with several paragraphs or Markdown links render correctly on the generated pages, and damage-state weights appear in the damage-state tables.

Distribution
------------

- Version 3.2 is published to PyPI as ``simcenter-dlml``. Versions 3.0 and 3.1 are now published as GitHub Releases as well, and the GitHub repository's ``releases/latest`` resolves to the current version instead of v2.1.0. Pelicun 3.10 and later install ``simcenter-dlml`` from PyPI and are unaffected. Pelicun 3.9 and earlier read the model data from the latest GitHub release and no longer work against it; the README's release policy describes the upgrade path and how to pin the data to v2.1.0.
