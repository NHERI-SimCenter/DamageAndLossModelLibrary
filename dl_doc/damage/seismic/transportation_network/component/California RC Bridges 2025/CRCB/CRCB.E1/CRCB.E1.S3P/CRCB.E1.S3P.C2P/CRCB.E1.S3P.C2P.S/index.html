The following models are available:

CRCB.E1.S3P.C2P.S.AbAct.BoxGirder.MCB.Circ.M17 | Active abutment fragility for an Era 1 (pre-1970) bridge with three or more spans, multi-column bents, and seat abutments. Model attributes: box-girder deck, bents with three to five columns, circular columns.

DesignSafe PRJ-5910 v1, Sa_1_Fragility Database.csv, data row 756 (spreadsheet row 758), group E1-S3P-C2P-S, AbAct; source note “Box-girder, circular column”. The curve describes the most-damaged unit of this component type in the bridge (the source analyses record one peak demand per component type), so assign a quantity of one per bridge. Curves for the same component and group from different sources are alternatives, and the database publishes no weights for choosing among them. The component curves do not carry the demand correlation behind the system curves. The component curves and the system curve of the same group (seismic/transportation_network/portfolio/California RC Bridges 2025) are two representations of the same bridge. Apply one or the other to a given bridge, because applying both to the same bridge double-counts its damage; different bridges in one regional assessment may use different representations.
Source study: Mangalathu (2017), a doctoral thesis that groups California box-girder bridges into classes by design era, span count, bent type, abutment type, and column shape, and derives component and system fragilities for each class from nonlinear time-history analyses. The fragility analyses use 320 scaled motions from 228 records of a Caltrans NGA-West2 suite listed in thesis Appendix A. Sa(1.0 s) is the RotD50 spectral acceleration at 5% damping: for 317 of the 320 motions, the Appendix A value equals the NGA-West2 RotD50 value times the tabulated scale factor.
The parameters are identical to those of CRCB.E1.S3P.C2P.S.AbAct.BoxGirder.MCB.Rect.M17; the duplication is in the source.

Suggested Block Size: 1 EA (round up to integer quantity)
