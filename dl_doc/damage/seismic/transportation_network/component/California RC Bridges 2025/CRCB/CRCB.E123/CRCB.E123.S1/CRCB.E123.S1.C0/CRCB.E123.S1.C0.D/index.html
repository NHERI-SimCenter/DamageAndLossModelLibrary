CRCB.E123.S1.C0.D - diaphragm abutments

The following models are available:

CRCB.E123.S1.C0.D.AbAct.Slab.Mod1.CPR22 | Active abutment fragility for a single-span (any era) bridge with no bents and diaphragm abutments. Model attributes: slab deck, modification factors from Era 1 two-span, single-column bridges.

DesignSafe PRJ-5910 v1, Sa_1_Fragility Database.csv, data row 0 (spreadsheet row 2), group E123-S1-C0-D, AbAct; source note “Slab deck, modification factors computed using Era 1 bridge fragilities”. The curve describes the most-damaged unit of this component type in the bridge (the source analyses record one peak demand per component type), so assign a quantity of one per bridge. Curves for the same component and group from different sources are alternatives, and the database publishes no weights for choosing among them. The component curves do not carry the demand correlation behind the system curves. The component curves and the system curve of the same group (seismic/transportation_network/portfolio/California RC Bridges 2025) are two representations of the same bridge. Apply one or the other to a given bridge, because applying both to the same bridge double-counts its damage; different bridges in one regional assessment may use different representations.
Source study: Cavalcante et al. (2022), a study of typical bridges in northeastern Brazil, including single-span T-beam and slab-deck bridges with seat abutments. Chen et al. (2025) use these curves as a proxy for California single-span bridges. They found no era-specific fragility models for single-span bridges, so the E123 groups apply to bridges of any era. The horizontal-component definition and the spectral damping of Sa(1.0 s) are not stated. In the literature they surveyed, Chen et al. (2025) found no viable set of fragility models for single-span bridges with diaphragm abutments. They derived this curve from the seat-abutment curve with modification factors, the ratios of the diaphragm-abutment to the seat-abutment fragility parameters of the two-span, single-column groups of the named era. The published values show the factors applied to the medians and the dispersions; the paper describes the adjustment of the medians only.
Chen et al. (2025) derived this curve with modification factors from the seat-abutment curve that the source labels AbAct (data row 26), which holds the passive-direction values. This dataset applies the same factors to the seat-abutment curve that holds the active-direction values (data row 28, relabeled here); each published value is multiplied by the ratio of the active-direction to the passive-direction seat value: slight median 17.56 g to 7.7179 g (ratio 0.4395); moderate median 78.73 g to 26.9499 g (ratio 0.3423); slight dispersion and moderate dispersion unchanged.

Suggested Block Size: 1 EA (round up to integer quantity)
